# Visualizalization-Practice 📊

This repository contains my practice exercises for data visualization using **Python**, **Pandas**, and **Matplotlib**. I am exploring how to represent business data (sales and profits) through various chart types.

## 🚀 Key Learning Objectives
* Customizing plot styles (colors, markers, and line types).
* Creating multi-line plots and grouped bar charts.
* Managing layout elements like `figsize`, `legends`, and `subplots`.
* Visualizing data distributions using Pie charts and Histograms.

---

## 📈 Visualizations Covered

### 1. Line Plots
Used to track product sales (Face Cream, Face Wash, etc.) over time. 
* **Customizations:** Marker styles (`o`, `s`, `D`), custom colors, and legend positioning.

### 2. Grouped Bar Charts
Comparing monthly sales across multiple product categories side-by-side.
* **Technique:** Shifting x-coordinates using `width` to prevent overlapping.

### 3. Pie Charts
Showing the market share contribution of each product to the total annual sales.
* **Features:** Used `autopct` for percentages and `bbox_to_anchor` to move legends outside the chart area.

---

## 🛠️ Tools Used
* **Python 3.x**
* **Pandas**: For data manipulation and CSV handling.
* **Matplotlib**: For generating high-quality static visualizations.
* **NumPy**: For coordinate math in bar charts.
